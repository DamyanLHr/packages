## Prose and headings

Write in plain sentences. Every `##` and `###` heading gets an anchor and shows
up in "On this page". Links, **bold**, _italic_ and `inline code` work as in
Markdown, and so do tables:

| Setting | What it does                                                  |
| ------- | ------------------------------------------------------------- |
| Density | How much the medium absorbs and scatters per unit of distance |
| Steps   | How many samples are taken along a ray                        |

## Maths

Inline maths goes between single dollars, like $T = e^{-\sigma d}$. A line of
its own goes between double dollars:

$$
T(d) = \exp\left(-\int_0^d \sigma(s)\,ds\right)
$$

## Citations

Cite a reference with its id, and it is numbered in the order of the
`references` list at the top of the file <Cite id="pbrt4" />. The list prints
itself at the end of the page.

## Code

Fenced code is highlighted at build time, in C#, HLSL, shell or anything else:

```csharp
public sealed class ExampleSettings : ScriptableObject
{
    [Range(0f, 1f)] public float density = 0.5f;
}
```

```hlsl
float Transmittance(float sigma, float distance)
{
    return exp(-sigma * distance);
}
```
