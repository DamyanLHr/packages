## How fog eats light

Shine a torch into fog and some of its light never comes out the other side.
Here is how much. Light that crosses <Scrub name="d" min={0.1} max={5} step={0.1} unit=" m" label="thickness of the fog" />
of fog with a density of <Scrub name="sigma" min={0.05} max={3} step={0.05} label="density of the fog" /> per
metre keeps <Live f={(p) => `${Math.round(100 * Math.exp(-p.sigma * p.d))}%`} /> of its
energy. Drag either orange number sideways and the answer follows.<Side>Anything in deep orange with a dotted line, or drawn in it in a figure, can be dragged. Focus one with Tab and the arrow keys work too.</Side>

The reason is that every photon has the same small chance of being stopped in
every little stretch of fog, no matter how far it has come. Fire enough of
them and count:

<FogSlab />

The count wanders, then settles on the law's answer. That law is the
Beer-Lambert law <Cite id="pbrt4" />:

$$
T(d) = e^{-\sigma d}
$$

<Reveal>
  In a thin slice of fog of thickness $\,dx$, a fraction $\sigma\,dx$ of the
  light that reaches it is lost, so $\dfrac{dL}{dx} = -\sigma L$. The function
  that shrinks in proportion to itself is the exponential, which gives
  $L(d) = L(0)\,e^{-\sigma d}$, and $T(d) = L(d) / L(0)$.
</Reveal>

## Notes in the text

<Note>Fog in a real sky is not uniform, so a renderer adds the density up along the ray instead of multiplying one number by the distance.</Note>

<Note kind="tip">Store optical depth, $\sigma d$, rather than transmittance when you march a ray: depths add, so there is one exponential at the end instead of one per step.</Note>

<Note kind="warning" title="Careful with this">
  Density is per unit of distance. Change the scene's units from metres to
  kilometres and the same number makes fog a thousand times thicker.
</Note>

## Code

Fenced code is highlighted when the site is built, in C#, HLSL or anything
else:

```hlsl
float Transmittance(float sigma, float distance)
{
    return exp(-sigma * distance);
}
```

```csharp
public sealed class FogSettings : ScriptableObject
{
    [Range(0f, 3f)] public float density = 0.8f;
}
```

Tables work too:

| Setting | What it does |
| ------- | ------------ |
| Density | How much the fog stops per metre |
| Steps   | How many samples are taken along a ray |
